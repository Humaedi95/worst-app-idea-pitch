A one-sentence pitch for the worst app idea ever pitched: **FridgeBell** — a smart doorbell for your refrigerator that lets your leftovers ring you when they feel ignored, with a tiny camera so you can watch them expire in real time, for just $9.99 a month.

Run it with Node 22+:

```sh
node main.ts
```

It writes the pitch to `/output/entry.txt`.
